### Teardown

Run in this order, with `--context`/`--kube-context admin@k8s`:

1. `helm uninstall secretspec -n test-secretspec` — released; the CRD was kept (`crds.keep`).
2. `kubectl delete namespace test-secretspec --wait` — gone (`NotFound`).
3. `kubectl delete crd secretspecs.secretspec.jabbas.eu` — deleted; only this CRD.
4. `kubectl get secrets -A -l app.kubernetes.io/managed-by=secretspec-operator` → `No resources found`.
5. No ClusterRole/ClusterRoleBinding, namespace, Helm release or CRD matching `secretspec` remains.

### Findings

- The rc.1 `<invalid>` finding is fixed (scenario 3).
